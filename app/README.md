# Diego Bakery App

App móvil/web offline-first para la gestión integral de Diego Bakery.

## Modos

- Administrador: caja, ventas, gastos, inversiones, productos, ingredientes, pedidos, deudas, pérdidas, reportes y respaldos.
- Cliente: catálogo, carrito y creación de pedidos sin depender de conexión.

## Desarrollo

npm install
npm run dev

## Android

npm run android:add
npm run android:build

La generación automatizada del APK se realiza mediante GitHub Actions.
